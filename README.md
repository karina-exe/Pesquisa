## 💚 Instruções de uso 💚

<p><b>Desktop:</b></p>

- Fazer o download do arquivo do script e abri-lo em qualquer IDE (VS Code, Pycharm, etc) ou no Python.

<p><b>Smartphone:</b></p>

- Android: Fazer download do script e abrir com o app Pydroid 3.
- iOS: Fazer o download do script e abrir com o app Pythonista.

Obs: Para fazer o download do script, basta abrir "TudoWeb.py" e clicar em "download raw file".

## 💚 Observações 💚

Existem duas versões do programa. A versão oficial (TudoWeb.py) e a versão de testes (Testes.py). 
A versão de testes é a simplificação da original, para facilitar provações.
